# 具身智能与 Agent：术语速查

以下是阅读本包时建议保持一致的译法。相同术语在不同论文中可能有不同边界，最终以作者定义为准。中文全文初稿已对常见短语施加固定译法约束；本表还补充缩写解释。2026-10-23 更新：常用缩写附英文全称；数据、算力和研究工具的更多全称见 09 补充工具地图。

## 1. 系统与任务

| 英文 / 缩写 | 中文 | 理解要点 |
|---|---|---|
| Embodied Artificial Intelligence（Embodied AI） | 具身智能 | 通过身体感知与行动，与环境交互 |
| Embodiment | 本体 / 具身载体 | 身体结构、传感器和动作接口影响能力 |
| Agent | 智能体 | 依据观测和目标进行交互决策的系统 |
| Agentic Robots | 智能体式机器人 | 组织目标执行、反馈、恢复和能力使用 |
| Policy / π | 策略 | 从可用信息到动作或动作分布的映射 |
| Observation / o | 观测 | 传感器或接口提供的信息，不等于真实状态 |
| State / s | 状态 | 建模世界与身体的相关变量 |
| Proprioception | 本体感知 | 关节、速度、执行器等身体信息 |
| Trajectory / Episode | 轨迹 / 一次任务记录 | 时间序列，可能包含观测、动作、奖励、终止 |
| Manipulation | 操作 | 用机械臂、手等改变物体与环境 |
| Locomotion | 运动 / 行走 | 移动机器人身体，维持稳定与跟踪目标 |
| Long-Horizon | 长时程 | 大量相互依赖的决策与交互，不能只按时长定义 |

## 2. 学习与模型

| 英文 / 缩写 | 中文 | 理解要点 |
|---|---|---|
| IL：Imitation Learning | 模仿学习 | 从示范行为学习 |
| BC：Behavior Cloning | 行为克隆 | 用专家动作作为监督标签 |
| RL：Reinforcement Learning | 强化学习 | 通过交互奖励优化长期行为 |
| SFT：Supervised Fine-Tuning | 监督微调 | 使用监督数据进一步调整模型 |
| PPO：Proximal Policy Optimization | 近端策略优化 | 一类策略梯度优化方法 |
| VLM：Vision-Language Model | 视觉语言模型 | 处理图像与语言，不自动提供机器人动作 |
| VLA：Vision-Language-Action | 视觉语言动作模型 | 连接视觉、语言与动作，具体边界依作者定义 |
| ACT：Action Chunking with Transformers | Transformer 动作分块 | 用条件序列模型预测动作块 |
| CVAE：Conditional Variational Autoencoder | 条件变分自编码器 | 用潜变量建模条件数据分布 |
| Diffusion Policy | 扩散策略 | 通过条件去噪生成动作序列 |
| Flow Matching | 流匹配 | 学习使样本沿连续流变化的向量场 |
| Action Chunking | 动作分块 | 一次预测多个未来动作，执行方式需另行定义 |
| Foundation Model | 基础模型 | 广泛预训练、支持多种下游任务的模型 |
| World Model / WM | 世界模型 | 捕捉环境动态，支持未来和反事实预测 |
| World-Action Model / WAM | 世界动作模型 | 将世界预测与动作生成结合，定义不完全统一 |
| Latent State / z | 潜状态 | 压缩后的状态表征，未必直接可解释 |
| RSSM：Recurrent State-Space Model | 循环状态空间模型 | 结合时间记忆与随机状态的动态模型 |
| JEPA：Joint Embedding Predictive Architecture | 联合嵌入预测架构 | 预测表征，通常不以逐像素重建为唯一目标 |
| Rollout | 轨迹展开 | 在真实环境或模型中执行 / 推演多步 |
| Counterfactual | 反事实 | 询问换成另一个动作会产生什么后果 |
| Credit Assignment | 贡献归因 | 判断长轨迹中哪些决定影响最终结果 |

## 5. 最容易混淆的五组

策略与世界模型：策略选择动作，世界模型预测动态；有些联合模型将两者结合。

VLM 与 VLA：前者处理视觉语言，后者与动作关联；是否直接生成低层指令需要核对定义。

长上下文与长时程：一个描述容量，一个描述复杂依赖与持续执行。容量增加不保证记忆、恢复或正确终止。

持久改进与递归改进：前者留下能力变化，后者还要求改进机制本身的功能性变化与继承。有效递归需要进一步证明以后改进能力提高。

P2-L1–L5 与 P5-L1–L5：P2 以自主权范围组织，P5 以人工介入、程序化更新、Imp 修改与泛化组织。务必附论文名和定义，不能只写编号。

## 6. 学习笔记推荐记法

首次出现写“世界模型（World Model，WM）”，后续使用 WM 或世界模型。保留论文、模型、数据集和基准的英文名称，方便检索。遇到翻译不顺或数学表达不清，立即根据译页标注回到原文，并在笔记里记录原词而不是继续猜测。
