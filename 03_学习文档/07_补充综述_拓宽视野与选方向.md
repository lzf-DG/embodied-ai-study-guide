## 2. S1：基础模型可以放在机器人哪里

公开记录：[arXiv:2312.07843](https://arxiv.org/abs/2312.07843)。Roya Firoozi 等，本包保存 v1。

### 核心问题

Foundation Model（基础模型）并不是某一种机器人控制器，而是经过广泛数据训练、能够支持多种下游任务的模型。它可以提供视觉特征、语言理解、规划、奖励、场景表示和行为先验。

这篇综述将基础模型背景、机器人学习与决策、感知、具身 AI 和挑战串起来。它的价值是帮助你画出系统中各类模型的位置，避免把“机器人使用大模型”只理解为端到端 VLA。

### 杯子例子

图文模型帮助找到“杯子”；几何 / 场景表示帮助确定位置；语言模型分解“清理桌面”；动作策略控制抓取；学习型评价器辅助识别完成。它们输入输出不同，可以模块化，也可以在某些结构中联合训练。

关键区别是 semantic knowledge 与 physical grounding。知道“杯子通常可以拿起”，不等于知道当前杯子是否粘在桌上、装了多少液体或能否被这个夹爪稳定抓住。

### 数据流伪代码

```text
目标对象 = 语言与视觉模型识别(任务, 图像)
空间状态 = 感知与几何模块估计(图像, 深度, 身体状态)
子任务 = 规划器(目标, 空间状态, 可用技能)
动作 = 策略(子任务, 最新观测)
执行并用环境证据验证
```

这不是某一个作者系统的实现，而是将综述分支连接起来的教学图。

### 主要取舍

预训练知识能减少每个新任务从零学习的成本，但机器人数据与互联网数据在动作、反馈、精度和物理后果上不同。冻结模型省算力，可能限制适应；微调改善特定任务，又需要合适数据且可能损失泛化。

模型的“知道”与“能做”之间仍需要执行接口、训练经验和评价。开放词表感知的成功，不直接意味着开放世界操作的成功。

### 第一遍读哪里

第 3 页看动机；第 4–8 页按需了解术语；第 8–16 页看机器人策略、规划和开放词表任务；第 16–21 页看感知与可供性；第 23–27 页看挑战。第一遍可跳过细致架构背景与大量引用。

读完写下三个不同位置的基础模型，分别说明它们的输入、输出、失败方式。自测：为什么识别出杯子仍不能完成抓取？答案应包含空间、动作、接触与执行约束。

## 3. S2：VLA 不只是一张大网络图

公开记录：[arXiv:2405.14093](https://arxiv.org/abs/2405.14093)。Yueen Ma 等。原文注明正式发表在 IEEE Transactions on Neural Networks and Learning Systems，DOI：[10.1109/TNNLS.2025.3650584](https://doi.org/10.1109/TNNLS.2025.3650584)。随包的是作者版本，不能代替最终期刊排版。

### 核心问题

本文分三条研究线：VLA 的组成组件、预测低层动作的控制策略、分解长任务的高层规划器。它适合回答“视觉、语言、动作分别怎么进入模型，以及低层执行与高层组织如何连接”。

有些文章将 VLA 用作较宽的概念，包含高层规划分支；较窄用法则强调从视觉语言到机器人动作。阅读时先看作者定义，不要求所有文章使用同一边界。

### 动作表示决定什么

动作可以离散为 token，也可以通过扩散或 Flow Matching（流匹配）等机制生成连续动作。离散化涉及精度、序列长度和自回归时延；连续生成涉及生成成本、分布表达与执行频率。

例如要把夹爪移动 3 毫米，动作表示的量化或单位会影响精度；生成十步动作块，执行时是否频繁重观测会影响反应能力。不同动作头不只是换一个输出层，它会影响训练目标与部署方式。

### 语言为什么有用

同一张桌子图像，“拿红杯子”与“把所有杯子收起来”要求不同动作。语言条件帮助任务选择和语义泛化。模型仍需要实际动作经验，才能把指令与机器人可执行行为连接。

相同句子在不同机器人上也需要不同动作：夹爪、灵巧手、单臂、双臂之间存在本体差异。跨本体泛化涉及观察接口、动作空间和行为语义，不能只靠共享语言输入完成。

### 教学伪代码

```text
训练样本 = 图像历史 + 语言目标 + 身体状态 + 专家动作块
视觉语言表示 = 编码器(图像历史, 语言目标)
动作分布 = 动作头(视觉语言表示, 身体状态)
按照所选生成机制计算学习目标并更新
部署时将生成动作转换到实际控制接口
```

这只是通用接口示意。具体模型是否使用历史、怎样编码身体状态、是否冻结主干，都需看方法。

### 如何判断泛化

分别检验未见对象、未见指令表达、未见场景、未见任务组合和未见本体。某一个维度提高不说明所有维度都解决。避免把“可以换一句提示”当成“可以执行任意新任务”。

### 第一遍读哪里

第 1–3 页看背景与分类；第 3–11 页选两种低层动作策略；第 12–14 页看 Task Planners；第 15–17 页看资源、挑战与结论。其后长参考文献用于查找方法，不需要通读。

读完比较 ACT、Diffusion Policy 和一个 VLA 的任务条件、动作表示、训练数据及执行接口。自测：大模型为什么仍需要机器人数据？答案应说明网络知识缺少与具体执行器关联的动作反馈。

## 4. S3：数据与评价可能决定模型上限

公开记录：[arXiv:2604.23001](https://arxiv.org/abs/2604.23001)。Ziyao Wang 等，2026-04-24，17 页预印本。[作者资源仓库](https://github.com/ziyaow1010/vla-datasets-benchmarks)。

### 核心问题

本文围绕 Datasets、Benchmarks、Data Engines 三个支柱，主张把高质量数据引擎和结构化评测共同作为研究对象。这是作者的研究判断，不是已经证明模型架构不再重要。

Dataset 是已有经验，Data Engine 是持续产生 / 筛选 / 标注经验的过程，Benchmark 是检验能力的协议。三者相互影响：数据覆盖影响策略，失败评测指导数据引擎，数据引擎又改变下一轮训练分布。

### 数据从哪里来

真机演示有真实接触与执行信息，但成本高；仿真便于规模化、自动标注和重置，却有 Sim2Real Gap；人类视频覆盖广，但通常缺少机器人动作与精确接触信息；视频重建与合成可以桥接部分缺口，物理一致性仍需验证。

不是轨迹数量越多越好。相同位置的一万条成功演示，可能不如覆盖遮挡、抓空恢复、不同形状的一千条有用。质量、覆盖、多样性、失败信息、跨本体对齐都值得考虑。

### 杯子例子：训练测试重叠

若训练和测试都来自同一桌面布局、相同物体位置或重复轨迹，成功率可能高估泛化。应说明划分单位：按轨迹随机分，按对象分，按场景分，还是按任务组合分？

一次“整理杯子”的成功也可能来自测试重置时夹爪已经靠近目标。重置方式、可见真值、人工干预和重试预算都属于协议，不能只报告模型结构。

### 数据闭环伪代码

```text
在独立条件中评估当前策略
将失败按感知、动作、恢复和任务组织分类
选择最需要补充的状态 / 任务
采集或生成候选轨迹
验证时间同步、动作语义、物理有效性与覆盖
用于训练；在未参与选择的测试集上重新评价
```

这里最容易混淆的是“用测试集指导训练”与“独立测量泛化”。开发集可用于选数据，最终测试集应保留独立用途。

### 本文的四类开放问题

Representation Alignment、Multimodal Supervision、Reasoning Assessment、Scalable Data Generation。分别关心不同数据 / 本体怎样对齐，怎样利用多种监督，怎样评估推理和组合能力，以及怎样可扩展地产生有效经验。

这些问题与 P1 的 Data、Environment，以及 P5 的 D 高度关联。但 S3 从具身数据与评价切入，能帮助你把抽象自我改进落到具体资料与协议。

### 第一遍读哪里

第 1–3 页建立定义，第 4–5 页看数据，第 6–7 页看基准，第 8–10 页看数据引擎，第 11–12 页看开放问题。全文正文相对短，适合完整读一遍。

一个低门槛实验是固定 ACT，比较等量数据下的简单采样与覆盖困难状态采样。先控制轨迹数量、训练预算和测试划分，再讨论数据配方的作用。

## 5. S4：SLAM 为什么仍然值得读

公开记录：[arXiv:1606.05830](https://arxiv.org/abs/1606.05830)。Cesar Cadena 等，IEEE Transactions on Robotics 32(6):1309–1332，2016，DOI：[10.1109/TRO.2016.2624754](https://doi.org/10.1109/TRO.2016.2624754)。本包为 v4，第一物理页是引用封面，因此 PDF 物理页码比正文印刷页码多 1。

### 核心问题

SLAM（Simultaneous Localization and Mapping）同时估计“我在哪里”和“世界地图是什么”。机器人移动时，如果自己的位置估计错了，即使任务语义正确，也可能走错门或把目标投影到错误坐标。

这篇经典综述覆盖系统结构、长期鲁棒性、规模、几何与语义表示、主动 SLAM 和新传感器 / 学习。它是空间估计与长期自主的机制教材，不是当前视觉语言导航的最新榜单。

### 前端与后端

前端从传感器提取并匹配信息，建立运动或位置约束；后端结合约束优化轨迹与地图。Loop Closure（回环检测）判断机器人是否回到旧地点，用旧新观测约束减轻累计漂移。

```text
新图像 / 点云 → 提取与关联特征 → 产生运动约束
约束 + 历史地图 → 后端优化 → 更新位姿与地图
若识别到曾经到过的位置 → 加入回环约束 → 全局调整
```

回环可能误识别：两个相似走廊不一定是同一个地方。错误回环会使地图变形，说明“有更多约束”不总是更好。

### 地图需要表示什么

Metric Map 关注几何位置、结构和可运动区域。Semantic Map 进一步表示房间、物体类别和关系。目标导航需要语义，精确避障和定位需要几何，两者可以结合。

语言模型说“厨房在客厅旁边”，不能替代当前环境中的几何定位；世界模型预测未来图像，也不一定提供可靠地图。不同能力可互相补充，但训练目标与误差性质不同。

### 长期自主为何困难

动态物体、光照、季节、地图规模、重复结构、传感器故障与不同观测视角都会带来问题。机器人持续运行，需要判断什么时候旧地图仍适用，什么时候应更新或重新定位。

Active SLAM 进一步考虑主动选动作以改善定位和地图，例如为了消除遮挡而换一个视角。动作不只服务任务，也可服务信息获取，这与具身交互的核心思想相通。

### 第一遍读哪里

PDF 第 2–5 页看引言与系统结构，第 6–9 页看鲁棒性与规模，第 10–13 页看几何 / 语义地图，第 15 页看 Active SLAM，第 18 页看结论。其他理论部分可在决定深入几何后阅读。

自测：地图和世界模型有什么区别？地图强调当前 / 已知空间结构与定位，世界模型强调状态随动作的变化；二者在某些方法里会融合，但不能根据名字就认为功能相同。

## 7. 怎样理解前沿发展脉络

一个有用的研究脉络是：传统几何与控制提供可执行基础；模仿学习与 RL 学习行为；基础模型提供广泛语义与表征；VLA 把知识连接到动作；世界模型帮助预测与规划；Agent 系统组织长期执行；持续 / 递归改进研究跨任务和跨轮次的能力积累。

这不是整齐的线性替代史。它们在真实系统中长期共存，数据与评测贯穿每一层。当前值得追问的研究问题包括：预测能否带来实际控制收益、长任务如何可靠恢复、跨本体数据怎样对齐、独立评测能否解释真实泛化、持续更新怎样避免遗忘与错误继承。

把这些问题与你能获得的实验条件结合，比单纯追逐最新模型名字更容易找到可以深入的方向。
