# P4：世界模型怎样帮助机器人

原文：A Comprehensive Survey on World Models for Embodied AI。Xinqing Li 等，arXiv:2510.16732v3，2026-06-25，23 页。[公开记录](https://arxiv.org/abs/2510.16732)。这里使用桌面 v3 版本，不把作者的 IEEE 会员称号或稿件格式当作已发表的证据。

## 1. 先懂一个问题

机器人看到杯子，知道可以抓，却未必知道从哪边抓不会碰倒旁边的瓶子。世界模型学习环境怎样随动作改变，让系统能够推演“如果这样做，会发生什么”。本文将其视作支持前向和反事实展开的内部模拟器。

前向预测是“执行这个动作后会怎样”；反事实预测是“若改成另一个动作，后果会不会不同”。要用于机器人控制，预测应与可执行动作有可靠关系，不能只评价生成画面是否像真实视频。

## 2. 最小数据流

![图12 世界模型的两条用途](图解/12_世界模型用途.png)

读图：学习动态与使用动态是两件事。当前规划比较候选动作；想象训练更新部署策略。编码器、先验 / 后验、损失与搜索过程在算法详解第 11、12 节展开。

```text
观测 o_t → 编码器 → 潜状态 z_t
潜状态 z_t + 动作 a_t → 动态模型 → 预测潜状态 z_(t+1)
预测潜状态 → 观测 / 奖励 / 价值 / 状态预测
这些预测 → 规划器或策略学习 → 下一动作
```

这里 z 是压缩表示，可以不是人能够直接解释的物理状态。具体模型可在像素、特征、对象、几何或其他状态上预测，并非都必须使用相同结构。

状态通常部分可观测：杯子被手遮挡后仍然存在，因此模型可能需要历史记忆或 belief state 来表示不确定性。单帧视觉特征不一定足以支持动态预测。

## 3. 本文三条分类轴

第一轴是 Functionality：Decision-Coupled 与 General-Purpose。前者学习与特定决策目标紧密关联的动态，强调控制与任务效果；后者希望覆盖更广环境和现象，强调可迁移的模拟能力。通用预训练目标与下游控制目标可能不一致。

第二轴是 Temporal Modeling：Sequential Simulation and Inference 与 Global Difference Prediction。前者按序展开未来，便于逐步动作控制，但长时程误差会累积；后者直接 / 并行估计未来状态，能降低长预测的时延，但频繁反馈与细粒度闭环控制可能更难。这里保留作者的原英文分类名，不将其简单改称为“扩散模型”。不同具体方法仍有各自的预测机制。

第三轴是 Spatial Representation：四种表示各有取舍。

| 表示 | 可以怎样理解 | 优势 | 代价与风险 |
|---|---|---|---|
| Global Latent Vector | 把环境压成紧凑向量 | 推演效率高 | 细致空间信息可能不足 |
| Token Feature Sequence | 用多个特征 token 表示场景 | 多模态、局部结构与注意力交互 | 计算和数据成本较高 |
| Spatial Latent Grid | 用 BEV、体素等有空间位置的网格 | 几何邻接、多视角融合与地图式规划 | 内存、分辨率及适应性取舍 |
| Decomposed Rendering Representation | 用 NeRF、3DGS 等可渲染结构表示 | 几何一致性和可控渲染 | 动态、接触、拓扑变化仍具挑战 |

三条轴可以组合。不要把“全局预测”误认为“一定使用全局向量”；一个描述时间建模，一个描述空间表示。

## 4. 为什么不一定需要预测每一个像素

对抓杯子来说，杯子位置、姿态、是否接触夹爪，可能比桌面纹理更重要。潜空间模型希望把计算集中在有用信息上；像素生成模型则提供直观且丰富的未来观测，但也可能在与任务无关的细节上花费算力。

Dreamer 系列是理解基于模型学习的代表入口：学习潜空间动态，在模型想象的轨迹中优化行为。RSSM（Recurrent State-Space Model）结合确定性记忆与随机状态，用来表达时间信息和不确定性。第一遍不要求推导所有损失，只需明白世界模型和策略承担不同功能。

JEPA 类方法强调预测表征而非逐像素重建。3D / 几何方法强调空间一致性。视频生成方法强调丰富的未来外观。这些目标相互联系，但不能互相替代。

## 5. 教学例子：预测得像，不等于抓得好

假设两套模型预测杯子抬起后的画面。A 的纹理漂亮，但误判夹爪没闭合时杯子也会上升；B 的纹理模糊，却正确预测抓空、滑落与碰撞。A 可能在视觉指标上占优，B 却更有利于动作选择。

因此要分层评价：像素预测质量、状态 / 几何理解、动作条件与物理一致性、最终任务效果。PSNR、SSIM、FVD 等指标有各自适用范围，不能单独证明模型具有可靠的物理理解。

本文正是将数据与指标跨机器人、自动驾驶和一般视频任务组织起来，并指出应更加重视物理一致性、实时效率和长预测可靠性。

## 6. 滚动规划与想象训练

世界模型的两种使用方式要区分。规划是在当前时刻比较候选动作，然后执行第一步再观测。想象训练是在模型生成的经验上改进策略，随后让策略直接执行。二者可组合，也具有不同误差路径。

```text
滚动规划示意:
    z = 根据真实观测更新当前状态
    对候选动作序列 A:
        预测未来状态 = rollout(world_model, z, A)
        score = 目标价值 - 风险 - 动作成本
    执行最高分序列的第一步
    用新观测纠正预测，再规划
```

这是导读补充的 MPC 风格示意。模型预测准确并不足以保证控制安全，尤其涉及分布外动作、接触和未知障碍时。

## 7. 长预测误差为什么会累积

一步预测偏一点，下一步把偏差当作输入，后续误差可能扩大。一个说明性的关系为 `e_(t+1) ≤ L e_t + ε`：ε 是新引入的预测误差，L 表示动态对误差的放大敏感度。它是教学示意，不是本文证明的普适误差界。

杯子接触桌沿时，小位置误差可能改变“稳放”与“跌落”的结果。相较平滑运动，接触、不连续事件和遮挡更难。重新观测可减轻累积，却受到感知质量和推理延迟限制。

## 8. 和 Agentic / RSI 的连接

Agent 可调用世界模型比较方案，或利用预测发现危险。但世界模型通常不负责完整任务管理。持续改进系统还能用真实失败更新世界模型，再利用改善的模型生成训练经验。

这也产生反馈风险：错误模型生成错误数据，策略学到错误规律，再产生偏置经验。因此需要真实或独立证据检验合成经验的有效性。模型与策略共同更新不自动构成递归自我改进，要看改进机制自身是否更新并帮助以后改进。

## 9. 第一遍阅读位置

先读第 1–3 页的动机、背景与三轴分类，尤其第 3 页图 1；用第 4 页表 I 找三种感兴趣的代表工作。随后按正文标题跳读 Data and Metrics、Performance、Challenges and Trends。不要第一遍逐行通读大型模型清单。

第二遍选择一个对照：潜空间与像素预测、序列与全局预测、2D token 与空间网格。比较时控制动作条件、数据规模和部署频率。

## 10. 小实验与自测

冻结同一策略 / 规划器，比较不用世界模型、使用模型筛选动作、使用更长预测时域三种条件。记录任务成功、碰撞、预测误差、总推理耗时。该建议用于学习，不代表已验证能形成论文贡献。

你应能回答：世界模型的输入是否包含动作？预测的是像素还是表征？预测目标与控制目标是否一致？推演时会不会走到训练未覆盖的状态？最终收益是否超过额外计算成本？

如果能回答这些问题，你已经可以开始阅读代表方法，而无需先理解所有模型代码。
